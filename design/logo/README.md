# ZinMD logo

The mark is a zellij rosette: the eight-point star and its eight petals, the
middle of a Moroccan tile pattern.

| File | Use it for |
| --- | --- |
| `mark.svg` | The mark on a light background |
| `mark-dark.svg` | The mark on a dark background |
| `mark-mono.svg` | One colour; it takes the colour of the text around it |
| `app-icon.svg` | The macOS app icon |
| `file-icon.svg` | The icon Markdown files wear in Finder |
| `png/` | PNG copies of the above |

Colours: mustard `#E1AD01`, light mustard `#EBC034`, ink `#1E1D1A`, cream `#FBFAF7`.

After changing a drawing, run `scripts/icon.sh`. It rebuilds the two `.icns`
files in `assets` and the PNG copies here.

The sketches that led here are in `design/ZinMD-logos.figcraft`.
